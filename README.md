# YYHealth
한국인 영양소 섭취기준(KDRIs)을 기반으로 한 개인 맞춤 영양 추천 시스템

본 프로젝트는 성별, 연령, 키, 체중, 신체활동 수준 및 질환 설문을 입력받아
KDRIs의 총에너지요구량(EER) 공식과 에너지 적정비율(AMDR)을 기반으로
하루 권장 칼로리와 탄수화물·단백질·지방 섭취량을 계산한다.

계산 로직과 설명 책임을 분리하여,
수치는 규칙 기반 엔진으로 산출하고
권장 근거는 KDRIs, JKMA, 국내 질환별 진료지침을 활용한
RAG(Retrieval-Augmented Generation) 파이프라인을 통해 제공한다.
